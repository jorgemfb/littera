# Registro de decisiones de Littera

Este documento conserva tanto las decisiones vigentes como alternativas **expresamente descartadas**. Sirve para no reintroducir opciones abandonadas al retomar conversaciones o trabajar con Codex.

| D02 | Toda la aplicación de edición tiene estética Zen permanente | Editor tradicional más un «modo Zen» añadido |
| D03 | Una sola fila de barra de título **nativa** | Dos barras apiladas o cabecera HStack dibujada debajo |

## Prioridad al leer decisiones históricas
La última decisión explícita prevalece sobre propuestas anteriores. La separación entre visual, funcionalidad y localización es contractual, no implica que los archivos jamás puedan cambiar: todo cambio visual debe solicitar revisión y respetar las capturas de referencia.
