The Littera window

Littera shows one document per window, with the text front and center. The top bar is the standard macOS one:

  • Document title, centered: a dot means unsaved changes. Click it to see the open documents (⇧⌘O).
  • On the right, document properties, the magnifying glass (⌘F) and the ··· menu with save, export, text width, typewriter mode, statistics and Settings.
  • The status bar (words, save state and mode) is hidden; turn it on in Settings → General.

Getting started

Open a document

  • File → Open… (⌘O) opens an existing .md file. You can also open it from Finder or drag it onto the Littera icon.
  • File → New (⌘N) creates a new document with its document properties ready.
  • When it starts with no documents, Littera creates an empty one (or shows the Open panel, depending on Settings → General).

Save

  • File → Save (⌘S) saves to the current file.
  • File → Save As… (⇧⌘S) saves under another name or location.
  • If the file changed outside Littera, it asks before overwriting it. If the file is read-only, Littera leaves it untouched and suggests Save As.

Recent documents

File → Open Recent, or the palette (⌘K or ⇧⌘O), which lists open documents first and then recent ones.

Editing modes

Littera has three modes. Switch with ⌘1, ⌘2 and ⌘3, from the View menu or from the palette (⌘K):

ModeShortcutDescription
Source⌘1Edit the Markdown with syntax highlighting.
Split⌘2Source on the left and preview on the right, kept in sync.
Preview⌘3Read-only, showing how the document looks.

Switching modes never copies or changes the file, and ⌘Z still undoes what you typed before switching.

Find and replace

  • ⌘F — Opens find.
  • ⌘G / ⇧⌘G — Next / previous result.
  • ⌥⌘F — Opens find with the replace field.
    • Replace replaces the current match.
    • Replace All replaces every match.

Search ignores case and accents.

Formatting

Every formatting command (headings, lists, quotes, code, tables, links…) is in the palette (⌘K). Three have default shortcuts:

ActionShortcut

Italic⌘I

You can assign shortcuts to the others in Settings → Keyboard shortcuts.

Document properties

The properties button in the top bar (also in ··· and in the palette) edits the document's YAML front matter without writing YAML:

  • Title (title): saved when you press Return or leave the field.
  • Status (status): Draft, In progress, In review or Done.
  • Tags (tags): type one or more separated by commas and press Return; the × removes one.
  • Created (created), as YYYY-MM-DD.
  • Generate table of contents (toc): shows a table of contents with level 1–3 headings at the top of the Preview, the PDF and the HTML.
  • Every other front matter key can be edited too: simple values as text, lists as tags, and objects or multi-line text as YAML.

New documents start with these properties ready. Each change can be undone with ⌘Z, and the YAML stays visible and editable in Source.

Assisted editing

  • Lists: Return on a list item (bullet, numbered, task or quote) adds the next one; on an empty item it ends the list. Turn it off in Settings → Editor → Continue lists.
  • Auto-pairing: typing (, [, {, ", `, * or _ adds the closing character; with text selected, it wraps it. Turn it off in Settings → Editor → Close brackets and quotes.
  • Paste a link: with text selected, pasting a URL (http, https or mailto) creates [text](url).
  • Transform text: with text selected, the context menu offers Uppercase, Lowercase and Capitalize.
  • From the palette (Editing group) you can trim trailing spaces and sort lines.
  • Insert date: choose the format in Settings → Editor → Date format.

Mermaid diagrams

A code block with the language mermaid is drawn as a flowchart in the Preview, in the right pane of Split and in exports (PDF and HTML). In Source it is edited as highlighted code.

```mermaid
flowchart TD
    A[Start] --> B{Saved?}
    B -->|Yes| C(Export)
    B -- No --> D[Save] --> C
```
  • Direction: TD/TB, BT, LR and RL, after flowchart or graph.
  • Shapes: [rectangle], (rounded), ([stadium]), ((circle)), {diamond}, {{hexagon}}, [[subroutine]] and [(cylinder)].
  • Links: -->, ---, -.->, ==> and <-->, labelled as -->|text| or -- text -->; several at once with &.

Littera draws diagrams offline and without JavaScript. Other Mermaid diagram types, or lines it does not understand, are shown as code with a notice.

Command palette

⌘K opens the palette: it searches documents (open and recent) and commands (modes, formatting, editing, export…) at the same time. Move with the arrow keys, confirm with Return and close it with Escape.

⇧⌘O, or a click on the title, opens the palette with documents only: the active and open ones first, then recent ones. Choosing a recent one opens it.

Typewriter mode

Turn it on from the ··· menu. The line you are editing stays centered and the rest of the text is dimmed.

Export

From the ··· menu, the palette or File → Export:

  • HTML — Creates an .html file with the rendered content.
  • PDF — Creates a PDF that looks like the Preview, including local images.

Images

Littera loads local images with relative or absolute paths once you authorize their folder. They are included in PDF exports.

Settings

Open them with ⌘, or from ··· → Settings. Changes apply immediately.

TabContents
GeneralLanguage, appearance (System, Light or Dark), status bar, initial view, restoring open documents, what to show when starting without documents, autosave and default folder.
EditorFont size, text width (Source, Split and Preview), highlighting, line spacing, typewriter mode, spelling, lists, auto-pairing and date format.
Keyboard shortcutsCustomize shortcuts for documents, search, views, formatting and editing.

Autosave

With Settings → General → Autosave, Littera saves documents that already have a file when you pause typing for a couple of seconds, when you switch apps and when you close them. New documents are saved the first time with ⌘S. If the file changed outside Littera, it is not overwritten. It is off by default.

Default folder and iCloud Drive

In Settings → General → Default folder, click Choose… to set where new documents are proposed and where the Open and Export panels start. It can be a folder on your Mac or in iCloud Drive (optional); Littera shows when it is in iCloud Drive. Changing it never moves the documents you already have.

  • If you open a document that is in iCloud but not on this Mac, Littera downloads it and opens it when done. Offline, it tells you.
  • If two devices save the same document at the same time, Littera asks: Keep both, Keep this Mac's or Use the other.

Privacy

Littera is a native macOS app and works without an Internet connection or an Apple ID. It sends no data to external servers. Documents are plain .md files, stored wherever you choose: on your Mac or, if you want, in iCloud Drive.

External changes

If another app changes the file while you are editing it, Littera asks whether to keep your version or load the one on disk. If you were not editing it, it reloads without asking.

Restore session

With the option on in Settings → General, Littera reopens the documents from the previous session when it starts.

YAML front matter

Littera recognizes a YAML block at the start of the document delimited by ---. It is highlighted in Source and Split and hidden in the Preview.

First launch (macOS Gatekeeper)

If macOS shows "Littera can't be opened" the first time:

  1. Go to System Settings → Privacy & Security.
  2. Scroll down to Security.
  3. You will see "Littera" was blocked because it is not from an identified developer. Click Open Anyway.
  4. Confirm by clicking Open in the next alert.

Littera does not yet have Apple's public distribution signature.
